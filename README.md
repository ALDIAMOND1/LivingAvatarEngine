# Living Avatar Engine — Nia

**Default character: Nia (original fictional identity).**

Run `OPEN_NIA.cmd` or open http://127.0.0.1:8765/ when the local server is running. Click Start talking once for browser microphone permission; afterwards speak to Nia.

Nia has a new warm portrait, curly hair, freckles, cream sweater, and independent prepared photographic blink/gaze states. This is still a research prototype, not true 3D head or realistic mouth lip sync. Browser speech recognition may use external cloud services. No general AI model is connected.

Nia files: `characters/nia/`, `src/nia-*.js` and `src/nia.css`. Original Ava files remain under `characters/ava/` for archival purposes.
