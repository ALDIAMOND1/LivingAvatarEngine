# Nia — Asset placeholders

There are intentionally **no fake photorealistic image or mesh files** here.

Expected paths:
- `portrait/nia-master.webp` — new original/consented portrait, currently MISSING.
- `face/neutral.ktx2` — neutral face texture, currently MISSING.
- `face/face.glb` — rigged face geometry, currently MISSING.
- `face/mouth-atlas.ktx2` — optional later speech texture atlas.
- `motion/blink.bin` — optional prepared eyelid correction.
- `motion/gaze.bin` — optional prepared gaze correction.

Do not rename arbitrary files to these names. Generate/prepare actual assets and update `config/assets.json` statuses only after validating them.

The reference livestream screenshot must NOT be reused as Nia's visual source without appropriate authorization.
